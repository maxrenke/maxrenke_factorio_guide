## Vanilla Progress Guide

A first-playthrough checklist that lives in your game. It breaks the road to your
first rocket into **15 ordered phases** - from mining your first iron to launching
a satellite - and ticks tasks off **automatically** as you play.

Built for new players doing a **vanilla** (base game, no Space Age DLC) run on the
2.0 engine. No hand-holding tooltips spamming your screen - just a quiet tracker
panel you open when you want to know "what's next?".

### Features
- **15-phase roadmap** covering power, the science chain (red -> green -> blue ->
  military -> yellow -> purple), oil, robots, solar, nuclear, modules/beacons, and
  the rocket silo.
- **Auto-completing tasks.** Research a tech, place a building, craft an item, or
  hit a production milestone and the matching task checks itself.
- **Manual checkboxes** for anything you'd rather track by hand.
- **Per-phase progress** with a clear "X / 15 phases complete" readout.
- **Multiplayer aware** - each player tracks their own progress.
- **Companion web guide (on GitHub).** The mod exports progress to a JSON file that
  a single-file HTML guide (deeper explanations, ratios, new-player traps) can import,
  or sync live. Link and setup in the section below.

### How to use
1. Enable the mod and start or load a save.
2. Click the **Guide** button in the top toolbar to open the tracker.
3. Play. Tasks tick themselves; click any checkbox to set it manually.
4. (Optional) Use the companion web guide below for the full walkthrough.

### Companion web guide (optional)
A single-file HTML guide with deeper explanations, ratios, and new-player traps
lives on GitHub. The mod exports your progress to a JSON file that the page can
import, or sync live. It is not bundled in this mod download.

Get it and the one-time setup steps here:
https://github.com/maxrenke/maxrenke_factorio_guide#readme

### Scope
This is a **vanilla, base-game, rocket-launch** guide. It intentionally stops at
the vanilla victory - the Space Age DLC planets are out of scope.

### Credits
Guide content is distilled from community tutorials by Trupen, Rkadindoubt, and
Nilaus - full credits and links are in the GitHub README.

 FAQ  (optional - append to the long description if you like)
--------------------------------------------------------------------------------
**Does this need the Space Age DLC?** No. It targets vanilla base game on 2.0.
The mod has no DLC dependency.

**Will it spoil the game?** It tells you the order of milestones, not how to build
each one. Think roadmap, not blueprint book.

**Does it change gameplay?** No recipes, entities, or balance are touched. It only
reads game state and shows a panel.

**Multiplayer?** Yes - progress is tracked per player.

**Where is the exported file?** %AppData%\Roaming\Factorio\script-output\guide_progress.json
